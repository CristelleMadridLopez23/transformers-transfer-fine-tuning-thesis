# Auditoría layerwise ABS₃

Auditoría OOF de estados L0–L12 y representación FINAL de MatGPT y MatterGPT originales. La selección por capa usa inner-validation; el test independiente permanece cerrado. Reproducir con `python scripts/ABS3/abs3_transformer_layerwise_audit/extract_layers.py`, `python scripts/ABS3/abs3_transformer_layerwise_audit/run_layerwise.py` y, si solo falta cerrar el informe, `python scripts/ABS3/abs3_transformer_layerwise_audit/finalize_outputs.py`.
