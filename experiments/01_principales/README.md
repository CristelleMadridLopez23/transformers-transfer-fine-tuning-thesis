# Experimentos principales

Contiene los cuatro resultados principales de extractores congelados.

- `matgpt_f0_stoichiometric_ridge_m2_comparison/`: MatGPT congelado con Ridge M2 y MLP8; incluye C0 SLICES-only y C1 SLICES + geometría.
- `mattergpt_abs3_frozen_ridge_mlp8/`: MatterGPT congelado, SLICES-only, Ridge M2 y MLP8.
- `mattergpt_abs3_geometry_late_fusion/`: MatterGPT congelado con SLICES + geometría, Ridge M2 y MLP8; conserva también referencias MatGPT históricas del mismo análisis.

Los nombres originales siguen disponibles como enlaces simbólicos relativos desde `experiments/` para preservar compatibilidad con scripts, informes y manifiestos existentes.
