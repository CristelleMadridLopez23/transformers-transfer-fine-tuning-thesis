# Experimentos complementarios

Aquí se agrupan los análisis metodológicos, auditorías y experimentos de ajuste fino que no forman parte de las cuatro condiciones principales de extractores congelados con/sin geometría.

Incluye estudios pairwise/kernel, suficiencia y capas de representación, el F4 directo, y el histórico de MatGPT.

Los nombres originales siguen disponibles como enlaces simbólicos relativos desde `experiments/` para preservar compatibilidad con scripts, informes y manifiestos existentes.
